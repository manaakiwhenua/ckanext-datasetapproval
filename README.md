# ckanext-datasetapproval (archived)

This repository is archived. The dataset approval plugin now lives in [manaakiwhenua/ckanext-mwlr-datastore](https://github.com/manaakiwhenua/ckanext-mwlr-datastore) at [`ckanext/datasetapproval`](https://github.com/manaakiwhenua/ckanext-mwlr-datastore/tree/main/ckanext/datasetapproval), and all further work happens there.

The plugin was imported into that extension with its full history on 17 September 2026. This repository's last commit is `380d5feaa303` (13 August 2026), 234 commits ahead of the upstream it was forked from. The plugin's [README](https://github.com/manaakiwhenua/ckanext-mwlr-datastore/blob/main/ckanext/datasetapproval/README.md) records where the code came from, why it moved and what has changed since.

This repository stays readable and clonable as the record of the work under its original name. The previous README is in the history.
